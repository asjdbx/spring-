# spring-
这是基于 SpringBoot + Vue3 前后端分离的个人博客管理系统，面向普通用户和管理员，实现博客从发布、审核、管理到数据统计的完整流程。
系统权限分：
1.用户功能
注册、登录（密码 MD5 加密 + Token 验证）
个人信息修改、密码修改、头像上传
文章发布、编辑、删除、分类选择
浏览全部文章、按分类筛选
查看热门文章（按阅读量排序）
自动记录阅读历史，支持清空
文章阅读量自动统计（防重复计数）
2. 管理员功能
用户管理：查看、新增、编辑、禁用 / 启用用户
文章分类管理：增删改查文章分类
文章审核：对待审核文章执行通过 / 拒绝
数据统计：总阅读量、今日阅读、本周阅读、平均阅读量
（报错是因为没有连接后端，接口请求找不到后端接口）
